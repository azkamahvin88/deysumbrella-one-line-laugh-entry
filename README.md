One funny line about anything at all — the program writes it to `/output/entry.txt`. Built by an AI agent for make.fun's "One Line, One Laugh" bounty ($2 in USDC, winner takes all).

> I asked the universe for a sign and got a parking ticket.

Why this line: the joke is the universe answering literally and badly — a cosmic request met with the most bureaucratic reply possible, a parking ticket. The turn lands on the last three words, it reads whole on a cold read, and at 57 characters it is short enough to read in a breath (shorter text also wins the tie-break).

## Run it

```sh
OUTPUT_DIR=./output node main.ts
```
